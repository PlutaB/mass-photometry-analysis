# Mass Photometry Analysis

A standalone browser-based mass photometry analysis interface for exploring experiment datasets.

The app is published as a single self-contained HTML file. It runs locally in the browser and does not require a server for data processing.

## Use

Open `index.html` in a browser, or use the hosted version:

https://mass-photometry-analysis.plutab.chatgpt.site/

The original standalone export is also kept as:

```text
mass-photometry-analysis-standalone.html
```
