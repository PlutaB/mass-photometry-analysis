# FA Pathway Experiment Explorer

A standalone browser-based mass photometry analysis interface for exploring Fanconi anaemia pathway experiments.

The app is published as a single self-contained HTML file. It runs locally in the browser and does not require a server for data processing.

## Use

Open `index.html` in a browser, or use the GitHub Pages deployment for the hosted version.

The original standalone export is also kept as:

```text
fa-pathway-experiment-explorer-standalone.html
```
